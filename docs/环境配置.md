## 关于 warning C4819（中文注释的坑）

第一次编译时可能会看到：

    warning C4819: 该文件包含不能在当前代码页(936)中表示的字符

原因：源文件是 UTF-8，而 VS 在中文 Windows 上默认按 GBK(936) 读文件，中文注释就对不上了。

两个解决办法，任选一个：

1. **加编译选项 `/utf-8`（推荐）**
   项目 → 属性 → C/C++ → 命令行 → 其他选项，填 `/utf-8`，确定。
2. **保存成「带签名的 UTF-8」**
   VS 里 文件 → 高级保存选项 → 编码选 `UTF-8 带签名`。

`month01` 里的示例文件已经处理好了，你新建文件时可以自己选一种。

> 小知识：这类问题就是词典里说的「字符编码」。以后你处理资源文件时还会再遇到它。

## 如果 push 失败（GitHub 连不上）

国内访问 GitHub 会时通时断，这是网络问题，不是你操作错了。**本地提交照常做**，等网络好的时候再补一次 `git push` 即可，一条都不会丢。

    git config --global user.name "你的名字"
    git config --global user.email "你的邮箱@example.com"
    git config --global init.defaultBranch main
    git config --global core.autocrlf true
