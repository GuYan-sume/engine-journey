## 变量
- 说人话：一个带名字的盒子，用来存东西。`double c;` 就是「造一个叫 c 的盒子，装小数」
- 为什么这个岗位在意：引擎代码里全是「位置、速度、血量、帧数」，都得先起个有意义的名字存起来
- 我在哪见过：温度转换里的 `c`；第一天想给 `h` 用却没先声明，报了 C2065

## 整数除法
- 说人话：两个整数相除，小数部分**直接砍掉**，不是四舍五入。333 ÷ 5 数学上是 66.6，用 int 只剩 66
- 为什么这个岗位在意：游戏里到处是坐标、血量、帧数运算，这种「不报错、不崩溃、就是悄悄算错」的坑最容易混进上线版本
- 我在哪见过：温度转换把 `double` 换成 `int`，输 37 得到 98 而不是 98.6（100 却没事，因为 900÷5 正好整除）
