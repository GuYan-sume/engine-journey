### 3 个收获（要具体到能讲给别人听）

1. 从零到能自己写出程序：`hello.cpp` → 温度转换 → 三档判断 → `while` 循环 → `for` 循环，一共 4 个工程、5 个 exe，代码是自己一行行敲的
2. 中文乱码彻底搞明白了：同一串字节，源文件编码 / 执行字符集 / 控制台代码页 三层只要有一层对不上就会变乱码；「2 个中文变 3 个乱码」是 UTF-8 被当 GBK 读的指纹
3. 会读编译器的报错了：红色 ✗ + `C###` 是真错误，蓝色 abc + `E###` 是 IntelliSense 重播；只看第一条 error，后面的常是它的连带反应

### 2 个卡点（写清楚你试过哪些办法）

1. 「改了代码却没生效」—— 白跑四次，原因是启动项目一直是 `week01_hello`，跑的是 hello.exe。以后跑之前先看左侧粗体的那个工程，再看输出窗口最后那行 exe 路径
2. 机械操作不熟：把已有代码搬进循环时缩进按多、提示语忘改；还撞上过文件开头多一个 BOM 造成的假报错（报错指着 `int main()`，真凶在第 1 行最前面一个看不见的字符）。这类问题靠 `Ctrl+K` `Ctrl+D` 排版 + 报错时先怀疑「行的最开头」来排查
