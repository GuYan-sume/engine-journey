# c-lang · 单文件 C 练习场

这个文件夹专门用来写 **C 语言**（不是 C++），主要配合头歌（EduCoder）的
「2026-2027-1-C/C++程序设计实训」使用。

**一关 = 一个 `.c` 文件**，不用建 Visual Studio 项目，写完直接跑。

## 为什么单独开一个文件夹

仓库主体（`month01/`）走的是 C++ 路线，按「一个程序 = 一个 VS 工程」组织。
但头歌的实训是一关一个小程序，为每关建一个工程太重了。所以这里用最轻的方式：
一个 `.c` 文件就是一个程序。

## 怎么用（三步）

1. **复制模板**：把 `template.c` 复制一份，改名成你要练的关卡，比如 `05_sum.c`
2. **写代码**：VS / VS Code 都行，但**必须存成 UTF-8 带签名**（见下）
3. **编译运行**：在仓库根目录打开命令行，敲

       c-lang\run.bat 05_sum.c

   它会先编译，再自动运行，一步到位。

懒得敲文件名的话，直接双击 `run.bat`，它会把本文件夹里所有 `.c` 文件列出来。

## 命名规则

    01_hello.c          序号 + 简短英文名
    02_char_ascii.c     对应头歌第 02 关「字符变换」
    03_reverse.c        对应头歌第 03 关「相反次序重新组合」

序号写成两位数，文件列表就会自动按关卡顺序排好。

## 文件说明

| 文件 | 干什么用 |
| --- | --- |
| `run.bat` | 编译并运行本文件夹里的 `.c` 文件 |
| `01_hello.c` | 环境验收：中文不乱码 + 能读输入，说明工具链没问题 |
| `template.c` | 空白模板，复制它开始写新的一关 |

## 编译会在这个文件夹里留下两个文件

跑完之后你会看到 `01_hello.obj` 和 `01_hello.exe`：

- `.obj` 是编译的中间产物
- `.exe` 是可以直接双击运行的程序

这两个都被 `.gitignore` 忽略了，不会提交到 GitHub。嫌乱就随手删掉，下次编译会重新生成。
## 三条必须记住的规矩

### 1. 后缀必须是 `.c`

`.c` 走 C 编译器，`.cpp` 走 C++ 编译器。写 C 却用了 `.cpp` 后缀，
很容易把 `iostream`、`cout` 这类 C++ 的东西混进来，到了头歌（gcc）反而编不过。

### 2. 文件存成 UTF-8 带签名

不然中文提示语会变乱码。VS 里：文件 → 高级保存选项 → 编码 → UTF-8 带签名。

本文件夹里的示例文件已经存好了，你复制出来直接改就行。

### 3. 只写标准 C

本地是微软的 MSVC，头歌是 gcc。坚持用 `printf` / `scanf` 这类标准写法，两边通吃。
**别用 `scanf_s`**——那是微软独有的函数，头歌上不存在。

两者完整差异见 `docs/环境配置.md` 的「写 C 语言」一节。

## 想用 Visual Studio 编也行

不喜欢命令行的话，按老办法建 VS 空项目，但要记得设两个属性：

- 预处理器定义里加 `_CRT_SECURE_NO_WARNINGS`（否则 `scanf` 会被当成错误）
- C 语言标准选 `ISO C17 (2018) 标准 (/std:c17)`

不设的话一定会卡在 `error C4996: 'scanf': This function or variable may be unsafe`。
详细步骤见 `docs/环境配置.md`。
