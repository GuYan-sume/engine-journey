## 工程结构（2026-09-17 起）

**一个程序 = 一个工程 = 一个 .exe**。以后加新程序，照这个套路来。

| 工程 | 源文件 | 生成的 exe | 是什么 |
| --- | --- | --- | --- |
| `week01_hello` | `hello.cpp` | `build\Debug\week01_hello.exe` | 工具链验收，确认「写-编-跑」通了 |
| `week01_mario` | `chaojimali.cpp` | `build\Debug\week01_mario.exe` | 字符画（双击 `看马里奥.cmd` 也能跑） |
| `week01_wendu` | `wendu.cpp` | `build\Debug\week01_wendu.exe` | 温度转换（本周的正式练习） |

三个词的关系，记住这一句就行：

```
解决方案 week01.sln   ← 一个「容器」，本身不产生 exe
 └─ 工程 .vcxproj      ← 一次编译的单元，一个工程产出一个 exe
     └─ 源文件 .cpp     ← 你写的代码
```

在 VS 里，**想跑哪个程序，就右键那个工程 → 设为启动项目**，然后 `Ctrl+F5`。
同一时刻只有一个「启动项目」在跑，所以再也不会撞「两个 main」。

## 卡住了看这里

- 报错只看**第一条**，`error C2143: 缺少 ";"` 这类，重点看它指的行和**上一行**。
- `Ctrl+F5` 不调试运行（窗口会停住），`F5` 调试运行。
- 装 VS 时**必须勾选「使用 C++ 的桌面开发」**，忘了就要重装。
- 输入温度用 `double`，用 `int` 的话 37 算不出 98.6。
- 如果 VS 建项目卡住了：`tools\build_run.bat month01\week01\hello.cpp` 可以直接编译运行（备选路径）。
- 看到 `warning C4819` 别慌，那是中文注释的编码警告，解决方式见 `docs/环境配置.md`。
