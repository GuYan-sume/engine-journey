## 怎么自己跑

这 6 个文件是**独立程序**，不在 VS 工程里。想跑就把某个文件的内容整个复制到
`week02` 里对应的**练习**文件（比如 `leap.cpp`），按 `Ctrl+F5`。
（别复制进 `考场\` 里的文件 —— 那是留着默写用的）

想深入就看注释：每个文件都写了「这一步为什么这么写」。
