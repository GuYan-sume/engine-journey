# 第 2 周补课 · 自测卷（考场）

## 规矩

1. **先看答案**（`..\答案\` 文件夹），跑一遍，看懂每一行为什么这么写
2. 然后**关掉答案文件夹**，打开 `week02_exam.sln`，一题一题默写
3. 每题都有**限时**。超时 5 分钟就去看答案 —— 看懂之后**把这个文件清空，从头再写一次**，那次才算数
4. 写不出来的地方就是没真懂的地方。圈出来，那才是今晚真正的收获

**怎么跑**：右边右键那一题 → 设为启动项目 → `Ctrl+F5`

## 交卷

写完跟我说一句，报三件事：**每题过没过 / 哪题重写过 / 总共花了多久**。
我按这张表打分，把错的几处讲一遍，然后填进 `docs\学习日志.md`。

## 分数怎么读

- **85 分以上**：第二周收工，直接进 week03（数组 + 字符串 + 调试器）
- **60 – 84**：错的那两题隔一天再默写一遍
- **60 以下**：不是你的问题 —— 这一周中间断了五天。答案再读一遍、跑一遍，明天重考一次
