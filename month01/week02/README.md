## 你一定会踩的坑（提前告诉你）

1. `5 / 2` 是 `2` 不是 `2.5`，因为两边都是整数。想要小数，至少一边得是 `double`。
2. `=` 是赋值，`==` 才是判断相等。写错编译器不一定报错，但结果一定错。
3. `cin >> a` 读到类型不对的东西时，后面的输入会全部错乱（先知道有这回事，以后再处理）。
