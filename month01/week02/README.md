## 你一定会踩的坑（提前告诉你）

1. `char` 用**单引号** `'A'`，字符串用**双引号** `"A"`；写成 `"A"` 会报
   `C2440: 无法从"const char [2]"转换为"char"` —— 因为 `"A"` 其实是 2 个字符：字母 + 结束符
2. `bool` 直接 `cout` 出来是 `1` / `0`，不是 `true` / `false`
   （想打印 `true`：`std::cout << std::boolalpha << x;`）
3. `C2143 缺少";"` 这类报错，位置常在**真凶后面一两行** —— 往上找那行没写完的
4. `&&` `||` `!` 的优先级比比较运算低，条件一复杂就加括号
5. 函数要写在 `main` 前面（或先在前面声明），否则报 `C3861 找不到标识符`
6. `vector` 下标从 **0** 开始，只存 5 个数时 `v[5]` 越界，编译器不报错但结果是垃圾
7. **`if` / `for` 后面多打的分号**：`if (x > 0);` 那个分号会被当成「空的一步」，
   不报错，但里面那句什么也没干（Day6 你踩过一次）
