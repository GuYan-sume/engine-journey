## 卡住了看这里

- 随机数：`std::srand(static_cast<unsigned>(std::time(nullptr)));` 然后 `std::rand() % 100 + 1`，需要 `#include <cstdlib>` 和 `<ctime>`。
- 循环写不出来，先用纸笔把 {5, 2, 9, 1} 的过程走一遍，再翻译成代码。
- 数组下标从 **0** 开始：`int a[6]` 的合法下标是 0 到 5。写 `a[6]` 就是越界（Week 4 会讲为什么危险）。
