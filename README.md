## 怎么编译运行（Visual Studio 2022）

1. 打开 Visual Studio 2022 → 创建新项目 → 空项目
2. 项目名称写 `week01_hello`，位置选到 `...\engine-journey\month01\week01`
3. 右侧「解决方案资源管理器」→ 右键「源文件」→ 添加 → 现有项 → 选 `hello.cpp`
4. `Ctrl+F5` 运行（`F5` 是调试运行）

以后每天重复这 4 步，项目名换成当天的名字。

> 快捷方式（可选）：开始菜单搜 Developer Command Prompt for VS 2022，cd 到当天目录后：
> `cl /EHsc /std:c++17 hello.cpp && hello.exe`
